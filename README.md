# Unity C# Academy — Part 15: Functions, Delegates & Events

Hinglish mein ek interactive, animated course website. `chapter` PDF (Part 15) ke content se bani hai.

- Line-by-line code animations (variables, loops, if-else, cube movement)
- Unity Editor mockup with guided tours (Hierarchy, Scene, Game, Inspector, Project, Console)
- Live demos: Update() loop, Rigidbody gravity, collisions, events, delegates, callbacks, mini game
- XP, levels, badges, streak, progress (localStorage mein save)
- "Sun ke samjho" — browser text-to-speech

Sirf HTML/CSS/JS, koi build step nahi. GitHub Pages pe seedha chalega: repo **Settings → Pages → Deploy from branch → `main` / root**.
